Known limitation

The source datasets do not share a reliable student identifier. The preprocessing script pairs rows by order for experimentation. This can create relationships that do not exist in real student data.

Project notes

What this project is, and what it is not.

What it does

It estimates exam scores and placement outcomes from student-related fields using two baseline machine-learning models.

What is complete

Data preparation, exploratory analysis, train/validation/test splits, baseline training, metrics, and structural checks are implemented.

What is left

Use genuinely linked student records, add repeated cross-validation, explainability, fairness checks, authentication, saved prediction history, and a production deployment process.
