Notes

What this project does, and what it does not do.

Scope

The project prepares two unrelated datasets, trains baseline models, and reports their test-set metrics. Exam score is a regression task. Placement is a binary classification task.

Data limitation

The exam file has no student identifier. The placement file has College_ID, but the exam file has no matching column. No row-order combined file exists in this version. Each track is split into train, validation, and test sets independently.

Preprocessing and validation

Imputation, scaling, and one-hot encoding live inside each scikit-learn pipeline and are fitted on the training split only. Every model is also evaluated with five-fold cross-validation. Training-versus-test gaps are written to outputs/metrics/overfitting_analysis.csv.

What is not claimed

No student-level link is claimed. No production accuracy is claimed. The placement label is deterministic in the source dataset; the investigation report explains why an unrestricted forest reaches a perfect score and why the deployed model is deliberately capacity-limited.

How to rebuild

Run the commands from the repository root:

python scripts/preprocess.py
python scripts/dataset_checks.py
python scripts/select_and_split.py
python scripts/data_quality.py
python scripts/pca_analysis.py
python scripts/run_eda.py
python scripts/train_baselines.py
python scripts/analyze_baselines.py

Then start the app with python app.py.
